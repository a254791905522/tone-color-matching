Tone Color Matching is an offline color matching puzzle game. Each level presents a target color, and your task is to recreate that color using Hue, Saturation, and Lightness sliders.

HOW TO PLAY
- Read the level brief: the target name and a short hint describing the color.
- Study the target color preview (shown on levels 1-5).
- Drag the Hue slider (0-360 degrees) to find the right color family.
- Drag the Saturation slider (0-100%) to set color intensity.
- Drag the Lightness slider (0-100%) to make the color darker or lighter.
- Tap Submit to compare your color against the target.
- Score is based on DeltaE, the scientific color difference metric. Lower DeltaE = higher score = more stars.

50 LEVELS OF COLOR
Progress through 50 color matching levels organized into five themed sets. Each set introduces new colors and gradually removes the training wheels, until you are matching shades purely from memory.

DIFFICULTY PROGRESSION
- Levels 1-5: Target color preview shown. Memory hint shown.
- Levels 6-10: Preview hidden, memory hint still shown.
- Levels 11-50: No hints. Pure color memory challenge.
- Difficulty scales 1-5 every 10 levels.
- 30-second time limit per level.

SCORING
- Score is calculated from DeltaE (CIE color difference formula).
- Lower DeltaE means a closer match and a higher score.
- Stars awarded based on score thresholds (1-3 stars per level).
- Best score per level stored locally.
- Total stars tracked across all levels.
- Level progression unlocks sequentially.

COLOR SYSTEM
- Hue: 0-360 degrees (red, yellow, green, cyan, blue, magenta cycle).
- Saturation: 0-100% (gray to full color).
- Lightness: 0-100% (black to white, 50% = pure color).
- Hex color shown in results for reference.
- DeltaE: scientific metric for perceived color difference.

FEATURES
- 50 color matching levels across 5 themed sets.
- HSL color matching with three sliders.
- DeltaE-based scoring system.
- Star ratings and best score tracking per level.
- Guided tutorial for the first 5 levels.
- Memory challenge: hints removed from level 11.
- 30-second time limit per level.
- Level select grid with sequential unlock.
- Settings with Sound, Music, and Haptics toggles.
- Fully offline. No ads, no IAP, no accounts, no tracking.
- Portrait orientation, iPhone only.

Tone Color Matching is a calm, atmospheric puzzle about training your eye to see subtle differences in hue, saturation, and lightness.
